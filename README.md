# Dashboard Suzuki — цифровая приборка для старых мотоциклов

**Dashboard Suzuki** — это кастомная цифровая приборка для мотоциклов Suzuki Bandit 400V и других старых японских мотоциклов.  
Она добавляет на экран смартфона информацию, которой нет на штатной панели:

- **Передача** (N, 1–6)
- **Температура двигателя** (NTC 50k)
- **Напряжение бортовой сети**
- **Состояние VC** (Variable Valve Control)

Проект полностью открыт и собран на базе ESP32 с передачей данных по Bluetooth.

---

## 🚀 Возможности

- Отображение передачи
- Отображение температуры двигателя
- Отображение напряжения бортовой сети
- Отображение состояния VC
- Настройка коэффициентов через приложение
- Работает с любым Android-смартфоном
- Красивый минималистичный интерфейс в стиле SUZUKI

---

## 🧩 Компоненты

- **ESP32 DevKit**
- **8 оптопар PC817**
- **NTC термистор 50k**
- **Резисторы:** 1к, 10к, 50к, 100к
- **DC-DC преобразователь 12V → 5V**
- **3D-печатный корпус (опционально)**
